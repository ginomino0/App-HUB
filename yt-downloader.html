🛠️ Prima Installazione & Risoluzione Errori

Prima volta o errore "The page needs to be reloaded"?
Se è la prima volta che usi lo strumento o se YouTube blocca il download, segui i passaggi sotto per configurare il PC in 1 minuto.
  1. 1. Prima Installazione (Installazione di yt-dlp e FFmpeg):
    Apri il Prompt dei comandi di Windows (CMD) e incolla questo comando per installare gli strumenti necessari:
    winget install --id yt-dlp.yt-dlp && winget install Gyan.FFmpeg
  2. 2. Aggiornamento manuale (Se yt-dlp è già installato via Python/pip):
    Se hai già il programma ma YouTube ti restituisce errori durante il download, aggiorna il componente digitando nel CMD:
    python -m pip install --upgrade yt-dlp
  3. 3. Esegui il download:
    Genera il comando in alto da questa pagina, clicca Copia, incollalo nel Prompt dei comandi (CMD) e premi Invio.
